## Video Express controls used

### 1. Start with the source

1. Open Video Express.
2. Open Media Library.
3. Import the source MP4 from the local Downloads folder.
4. Add the imported clip to the timeline.
5. Use the Save control after major milestones.

### 2. Use the correct redesign workflow

For an AI-generated clip that has the wrong characters, dialogue, or storyline:

1. In Media Library, locate the clip.
2. Right-click the clip.
3. Choose **Redesign**.
4. Rewrite both the image prompt and the video/audio prompt.
5. Keep the character description identical across related clips.
6. Generate and review the new clip.
7. Add the approved result to the timeline.

Do not use **Fix Video** when the problem is story, character identity, dialogue, or scene content. **Redesign** is the appropriate control for those changes.

### 3. Keep characters consistent

Use Media Library > My AI Images as the character reference source.

Recommended setup:

- Select a clear hare/tortoise reference image.
- Choose the 3D image type.
- Enable **Use Consistent Character**.
- Add the reference through **Use from Library > My AI Images**.
- Use the same character wording in every prompt:
  - friendly blue-capped hare
  - gentle green tortoise
  - warm 3D animated storybook style
  - Buttercup Meadow setting
- Avoid introducing unrelated reference images or unrelated clips.

### 4. Creative mode

Use **Creative mode** when a new scene needs more expressive staging, stronger visual composition, or a fresh but compatible interpretation.

Keep Creative mode constrained with:

- the same character description
- the same clothing and colors
- the same setting
- clear dialogue instructions
- “no extra characters” when consistency matters

### 5. Story structure

A strong general-purpose structure for this story is:

1. Hook: the hare confidently challenges the tortoise.
2. Stakes: the animals gather and the race begins.
3. Contrast: the hare moves quickly while the tortoise stays steady.
4. Turning point: the hare becomes overconfident and rests.
5. Progress: the tortoise continues without stopping.
6. Payoff: the tortoise reaches the finish line first.
7. Lesson: steady effort, humility, and perseverance matter.

Keep each scene focused on one action or one spoken idea. Remove clips that introduce unrelated people, locations, or wording.

### 6. Timeline and pacing

- Add clips in clear story order.
- Use Fast Cut when the timeline needs tighter pacing.
- Review the ruler and total runtime before export.
- For a longer lesson, expand with meaningful story beats rather than unrelated filler.
- Preview transitions and check that dialogue is understandable.

### 7. Export settings

Use:

- Quality: High
- Resolution: FullHD
- Format: MP4
- A descriptive filename, for example:
  hare-tortoise-5-minute-hd-lesson

After export, verify the downloaded file duration and resolution before uploading.

## YouTube publishing workflow

1. Open YouTube Studio.
2. Choose Upload videos.
3. Select the exported MP4.
4. Use a title with the story name and lesson.
5. Put the story promise and moral in the first lines of the description.
6. Set the audience accurately. This story was marked **Made for kids**.
7. Wait for upload, HD processing, and copyright checks.
8. Choose Public only after reviewing the final details.
9. Publish and verify that YouTube reports the video as published.

## Retention guidance

An 80% retention rate cannot be guaranteed because it depends on audience, thumbnail, title, traffic source, and viewer expectations. To improve the odds:

- Start with action or a question in the first seconds.
- Avoid unrelated clips and slow introductions.
- Change visual framing regularly while preserving character identity.
- Keep dialogue short and natural.
- Make the lesson payoff clear at the end.
- Review YouTube audience-retention data after the video has enough views, then redesign the exact drop-off moments.

## Safety and account notes

- Never store Google passwords, YouTube cookies, API keys, or GitHub tokens in this repository.
- Keep the original YouTube upload until the new version has been verified.
- Delete an older upload only after confirming the new public video is working and retaining any needed analytics.
