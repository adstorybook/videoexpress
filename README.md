# Two-story video package

Separate project briefs, narration drafts split into 13 short segments each, and promo pages for the two stories in the supplied storybook:

- The Clever Little Rabbits — child-friendly safety, courage, and teamwork.
- Mother Magpie — gentle grief, kindness, and belonging.

Both scripts use an opening curiosity hook, quick visual changes, and a warm resolution. Target runtime is approximately 5:16–5:26 at the slow narration pace already used in VideoExpress. Retention above 80% is an aim to test against channel analytics; it cannot be promised in advance.

Both project briefs also include the user's Alex and Maya reference characters as consistent storybook hosts in the opening and closing frames; the rabbit and magpie characters remain the fables' protagonists.

VideoExpress currently limits imported audio to 30 seconds in its old lipsync window on this account. Its upgrade dialog says an upgrade allows audio up to 300 seconds. The segmented route works: a 254-character Jenny/Friendly voiceover at speed 0.7 rendered as 22 seconds; the first rabbit project draft has short video clips, a still frame, and a narration sample on separate tracks. Neither story has a finished MP4 yet; the saved 32-second travel clip is unrelated. Promo pages are drafts; YouTube links are placeholders until an approved upload exists. The YouTube channel is not connected to the publishing workspace.

Reusable editor notes, observed limits, and the scene-by-scene workflow are in [VideoExpress workflow notes](videoexpress-workflow-and-limitations.md).
